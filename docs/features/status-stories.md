# ⭕ 24h-Status / Storys

Teile spontane Momente, Schnappschüsse oder Gedanken mit deinen Kontakten. Nach 24 Stunden verschwinden die Einträge automatisch.

---

## 1. Eigenen Status erstellen

1. Klicke in der Navigationsleiste auf das **Status-Symbol (`⭕`)**.
2. Tippe auf **„Mein Status“** (bzw. das **`+`**-Symbol).
3. Du kannst:
   * Einen kurzen **Text-Status** schreiben (*„Was machst du gerade?“*).
   * Ein **Foto oder Bild** hochladen (z. B. frisch erstellt aus dem [KI-Bildstudio](/features/ki-bildstudio)).
4. Klicke auf **„Status posten“**.

---

## 2. Storys deiner Kontakte ansehen

* Unterhalb deines eigenen Status siehst du alle aktiven Storys deiner Familie und Freunde.
* Ein Klick auf einen Kontakt öffnet den Story-Player im Vollbild.
* Ein Fortschrittsbalken oben zeigt an, wie lange die aktuelle Story noch sichtbar ist.
