# 📞 Sprach- & Videoanrufe

Über das **Telefon-Symbol (`📞`)** in der Navigationsleiste oder direkt aus jedem geöffneten Chat erreichst du die kristallklaren VoIP-Funktionen von ChatConnect.

---

## 1. Direktanruf aus einem Chat

* Öffne die gewünschte Unterhaltung.
* Tippe oben rechts auf:
  * 📞 **Hörer-Symbol:** Für einen reinen HD-Sprachanruf.
  * 📹 **Kamera-Symbol:** Für einen Videoanruf mit Front- oder Hauptkamera.
* Der Gesprächspartner erhält sofort ein Anruf-Signal auf seinem Bildschirm.

---

## 2. Der Anrufe-Bereich (`📞`)

In der Navigationsleiste findest du die vollständige Anrufzentrale:
* **Neuer Anruf:** Starte direkt ein Gespräch mit einem beliebigen Kontakt.
* **Anruflink erstellen:** Erzeuge einen sicheren Einladungslink, über den andere Teilnehmer ohne Umwege beitreten können.
* **Ziffernblock (Wählfeld):** Direkteingabe für IDs oder Nebenstellen.
* **Anrufprotokoll:** Übersicht aller verpassten, eingehenden und ausgehenden Telefonate.

::: tip Berechtigungen
Stelle beim ersten Start sicher, dass dein Browser die Berechtigung für **Mikrofon** und **Kamera** erhalten hat.
:::
